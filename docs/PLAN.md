Лид Вячеслав-3.2 → исполнитель Алексей. Источники: промпт (части А и Б), обзор текущего сайта, отзывы, курс «AI-Архитектор» (демо-принципы: реалистичный контент вместо пустых состояний, мобильная проверка, чистая консоль, читаемый URL, не дорабатывать бесплатно сверх концепта).

## 0. Цель
Статический сайт-концепт (Next.js 16 `output: 'export'`), который директор и учредители откроют с телефона до первого разговора и увидят, что он на порядок лучше нынешнего Битрикс-сайта. Идея: **«Всё делается в школе. Домой ребёнок приходит свободным.»**

## 1. Что нашли в материалах (кратко)
- Промпт разрешает только проверенные факты; теперь многие заглушки закрываются: корпус **5**, годы 2002, реальные цены без допущений, распорядок дня, ОГРН/ИНН. Детали — `FACTS.md`.
- Найдены противоречия на их сайте (медали, возраст сада, цены сада, 3 vs 4 приёма пищи, чужие адреса в /sveden) — не повторяем, выносим в вопросы клиенту.
- Сад считается за **12** месяцев (1 080 000 / 90 000), школа за 9 — в промпте стояло «по умолчанию 9» для сада.
- Требование про версию для слабовидящих исключено из приказа Рособрнадзора в 2025, но на их сайте оно есть — делаем (в промпте требуется).
- Из курса берём только демо-практику; Vercel и Supabase не нужны (в промпте — Cloudflare Pages / GitHub Pages).

## 5. Ключевые технические решения
- **Контент отдельно от кода** — ни одной цены/телефона в компонентах.
- **Заглушки** — единый компонент `<Ph>` (пунктирная рамка, приглушённый цвет); скрипт собирает все `[…]` из `content/`.
- **Scroll-сцена**: GSAP `matchMedia` — pin+scrub только ≥768 px и без reduced-motion; иначе `IntersectionObserver`-появление.
- **Анимации** только `transform`/`opacity`/точечно `filter`.
- **Формы**: клиентская валидация (RHF+zod) → текст заявки → мессенджер; персональные данные нигде не сохраняются. Каналы по умолчанию — см. D-07.
- **Слабовидящие**: класс на `<html>`, `localStorage` в try/catch, крупный шрифт, высокий контраст, `animation: none`.
- **Фото**: стоки Unsplash/Pexels без лиц детей (руки, книги, свет), подписи `[фото школы — от клиента]`. Нужен доступ в сеть для скачивания; если недоступен — SVG-иллюстрации + заглушки (D-09).
- **Метка концепта**: noindex, `Disallow: /`, строка в футере (студия Kovagor).

## 6. Риски
1. Сеть: живой сайт и, возможно, Unsplash недоступны из окружения → контент берём из присланного; фото — запасной план.
2. WhatsApp ограничен в РФ → основной канал Telegram/MAX, WhatsApp вторичен.
3. Cloudflare Pages из РФ бывает нестабилен → GitHub Pages как резерв, проверка вручную.
4. Противоречивые данные клиента → только заглушки и вопросы, ничего не угадываем.
5. Юридика: сайт-концепт, ПДн не собираются; но на `/privacy` — заглушка и пометка «не является официальным сайтом».
