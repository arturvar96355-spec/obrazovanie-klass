## 4. Из отзывов (R) — что можно использовать

Дословные цитаты с авторами и датами — в `docs/REVIEWS.md` (банк для `content/reviews.ts`). Перед показом клиенту сверить с оригиналом на Картах. Темы по частоте: ребёнок идёт сам, сад+школа в одном здании, маленькие классы, питание, ДЗ в школе, без репетиторов. Минусы (стадион, цена) — не скрываем в тексте, но и не выносим в цитаты.
Цитата из P «Директор буквально «живёт» своей школой» в банке R не найдена — оставляем по P, помечаем `[сверить с оригиналом]`.
